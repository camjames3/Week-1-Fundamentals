# Week 1: Web Fundamentals
A simple HTML/CSS page built to learn web structure, styling, and Git basics.

## How to Run
1. Open `index.html` in any browser.
2. View styles in `style.css`.

## What I Learned
- HTML structure: `<head>` vs `<body>`
- CSS: selectors, colors, line-height, padding, `rem` units
- Git: init → add → commit → push to GitHub
